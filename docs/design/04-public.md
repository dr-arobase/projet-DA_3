# Public

Trois profils, trois contextes de travail très différents. Un écran est toujours conçu pour l'un d'eux en priorité.

## Policier (sergent autres fonctions)

- **Où** : sur le terrain ou dans une voiture de patrouille, souvent sur téléphone, parfois avec une mauvaise connexion.
- **Quand** : par à-coups, entre deux interventions, souvent sous pression.
- **Ce qu'il veut** : vérifier en quelques secondes si une personne est recherchée, voir la dernière adresse connue, signaler une observation, recevoir une alerte urgente sans la chercher.
- **Ce qui le gêne** : chercher longtemps, taper beaucoup, des informations périmées, un écran qui ne tient pas sur un téléphone, une alerte qu'il manque.
- **Conséquence pour le design** : recherche et alerte toujours à portée, gros boutons, peu de saisie, état « hors ligne » visible.

## Superviseur (sergent gestionnaire à inspecteur-chef)

- **Où** : au poste, sur ordinateur, plusieurs onglets ouverts.
- **Ce qu'il veut** : tenir le registre à jour, diffuser une alerte à tout le monde, voir qui est connecté, gérer les comptes de son équipe.
- **Ce qui le gêne** : écraser par erreur la modification d'un collègue, ne pas savoir si son alerte est partie, des actions irréversibles sans confirmation.
- **Conséquence pour le design** : confirmations pour ce qui ne se défait pas, retour clair après chaque diffusion, conflits expliqués.

## Direction (directeur général et adjoint)

- **Où** : au bureau, sur ordinateur.
- **Ce qu'il veut** : une vue d'ensemble fiable (statistiques), la gestion de tous les comptes et grades, le journal d'audit.
- **Ce qui le gêne** : des chiffres faux ou fictifs, ne pas pouvoir retrouver qui a fait quoi.
- **Conséquence pour le design** : chiffres justes et datés, traçabilité visible, pas de décoration.

## Pour tous

- Ils connaissent le métier, pas l'informatique : le vocabulaire est celui du poste (voir `02-voix.md`).
- Ils peuvent être deux à modifier le même dossier : l'interface doit gérer le conflit avec calme.
- L'application sera **évaluée par l'enseignant** avec un compte GitHub inconnu (rôle policier) et les comptes de démonstration du README, dans deux navigateurs, avec au moins une action refusée.
