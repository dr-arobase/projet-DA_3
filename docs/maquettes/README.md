# Maquettes — CrimeTracker

Créez les maquettes avec l'outil de votre choix (Figma, Excalidraw, Penpot, Moqups).

## Écrans à produire (4–5 obligatoires)

| Fichier attendu | Écran | Priorité |
|---|---|---|
| `01-login.png` | Page de connexion (formulaire badge + mot de passe, message d'erreur) | Obligatoire |
| `02-dashboard.png` | **Tableau de bord temps réel** — flux d'alertes, indicateur d'agents en ligne, derniers changements de statut (cœur de l'application) | Obligatoire |
| `03-criminals-list.png` | Liste des dossiers — filtre par statut/nom, indicateur visuel par statut (recherché / capturé / libéré), pagination | Obligatoire |
| `04-criminal-profile.png` | Profil d'un dossier — photo, identité, crimes, historique de statuts, bouton de mise à jour (agent), bouton de suppression (superviseur uniquement) | Obligatoire |
| `05-add-criminal.png` | Formulaire d'ajout de dossier (superviseur) — champs requis, validation, message de confirmation | Recommandé |

## Notes
- Chaque maquette doit être **titrée** et **annotée** pour ce qui n'est pas évident : contenu des menus, états d'erreur, différences d'interface selon le rôle.
- Nommez les fichiers exactement comme dans le tableau pour correspondre aux liens dans `03-conception.md`.
